# 自作Android IME 設計仕様書

## 概要
Android用の自作ソフトウェアキーボード(IME)。30%キーボードのようにキー数を絞り、
レイヤー切り替えで機能を切り替える設計。

## 技術方針
- `InputMethodService` を継承した独自IMEとして実装(Kotlin想定)
- ローマ字→かな変換、および将来的な漢字変換(かな漢字変換)は、
  Mozcエンジンを組み込んだ既存OSS(例: mozkey, OyaMozc)をforkして土台にする方向を検討中。
  ゼロから変換エンジンを実装するのではなく、既存実装のレイヤー/キー配置部分を
  自分の設計に置き換えるアプローチを優先する。
- 全角/半角の切り替えは、ASCII文字とUnicode全角文字の対応表による単純変換で実装可能。

## 物理レイアウト
- 4段構成(数字専用の段は設けない)。いわゆる30%キーボード(Planck等)に近い配列。
  - 1〜3段目: QWERTY配列26キー
  - 4段目: 機能キー段(スペース・エンター・シフト・ローマ字入力切替・レイヤー切替・Backspace)
    - スペースキーは他キーより幅広に確保する
- Backspaceキー: QWERTY最上段(Pキー)の右側にさらに1キー追加し、横一列の右端に配置。
  レイヤー1・レイヤー2の両方に同じ位置で配置する(レイヤーを跨いでも位置が変わらないようにする)。

## レイヤー構成(トグル型切り替え)
レイヤー切り替えキーは「押すたびに固定/解除」されるトグル方式。
現在のレイヤーが一目でわかるよう、配色や切り替えキーの見た目を変える等の
視覚的フィードバックを必ず入れる。

### レイヤー1(基本レイヤー)
- ローマ字キー(QWERTY配列、26キー)
- Backspaceキー: QWERTY最上段右端に配置
- スペースキー:
  - タップ: 半角スペース入力
    - ただし、かな漢字変換の候補選択中(未確定文字列がある状態)にタップした場合は
      「次候補」へ送る動作になる(下記「かな漢字変換操作」参照)
  - 長押し: Tab入力
  - 左右スワイプ: カーソルを左右に移動(Gboardのカーソル移動ジェスチャーと同様)
  - 上下スワイプ: カーソルを上下(行単位)に移動
    - 実装方式: 固定閾値(縦方向の移動量)を跨ぐたびに1行移動する、ドラッグ操作に近い方式。
      指を離すまで連続して複数行移動できる。左右スワイプのカーソル移動と同じロジックを
      縦方向に流用する形で実装する。閾値の具体的な数値は実装しながら調整する。
  - 候補選択中に長押し/スワイプを行った場合: 先頭候補を確定してから、通常時と同じ動作
    (Tab入力 / カーソル移動)を実行する。
- エンターキー
- シフトキー:
  - タップ: モーメンタリ(次の1文字のみ大文字化、入力後は自動解除)
  - 長押し: ロック(CapsLock的に常時大文字化。解除は再度タップ/長押し)
- ローマ字入力切り替えキー:
  - タップ: ローマ字入力 ⇄ 直接英数入力の切り替え
  - 長押し: 全角 ⇄ 半角の切り替え
- レイヤー切り替えキー(トグル): レイヤー2へ切り替え

### レイヤー2(記号・数字レイヤー)
- 数字キー(0〜9)
- 記号キー(#, *, -, _, +, (, ), /, :, >, `, ~, [, ], {, }, ", ' など)
  - Markdown記法(#, *, `, >, - など)もこのレイヤーの記号配置で対応する。
    専用のMarkdown入力レイヤーは設けない。
- Backspaceキー: レイヤー1と同じ位置(横一列の右端)に配置
- レイヤー切り替えキー(トグル): レイヤー1へ戻る

## かな漢字変換操作(Mozc統合時)
- 「変換」専用キーは設けない。ローマ字入力に応じて候補バーに変換候補を自動表示する、
  Gboard日本語などのモバイルIME標準スタイルを採用する。
- 「次候補」(候補送り): 候補選択中(未確定文字列がある状態)にスペースキーをタップすると
  次の候補へ送る。未確定文字列がない通常時は、スペースキーのタップは半角スペース入力。
- 候補確定: 候補バーのタップで即確定。何もせず次の文字入力やEnterを行った場合は
  先頭候補が自動確定される。

## 未確定・今後決めること
- レイヤー2(記号・数字レイヤー)の物理配置(何段・何列に数字と各記号を割り振るか)
- レイヤー切り替え時の視覚的フィードバックの具体的な仕様(配色パターン、
  切り替えキーの見た目の変化など)
- スペースキー上下スワイプの閾値の具体的な数値(実装しながら調整)

## 実装上の注意点
- スペースキー1つに「タップ／長押し／左右スワイプ／上下スワイプ」の4種のジェスチャーが乗り、
  かつ「かな漢字変換の候補選択中かどうか」で意味が変わる状態依存キーになるため、
  タッチイベント処理での移動距離の閾値・長押し判定タイマーによる分岐に加えて、
  IME側の変換状態(未確定文字列の有無)を参照した分岐が必要。
- レイヤー切り替え時は `Keyboard` オブジェクト(表示するキーレイアウト)を
  差し替える実装になる。Backspaceキーなど両レイヤー共通のキーは同じ位置に
  配置し、レイヤー切り替え時の位置感覚のズレを防ぐ。
